# SchemaSeed v0.3.4

## 新功能与修复

- 预览仅由用户显式点击生成；首次打开、切表及手动修改配置不会隐式生成或复用过期数据。
- 将预览操作简化为「生成预览」和「换一批数据」。「换一批数据」使用不同 Seed、更新 Seed 输入并立即生成，并防止重复请求和旧上下文异步结果覆盖。
- 改进受 DBX Host 授权控制的采样证据及语义确认；样本不足或语义不充分时不会自动确认，拒绝授权或采样失败时安全回退。
- 增加 MySQL JSON 类型的合成生成及规则支持，区分 JSON 文档 `null` 与 SQL `NULL`，并贯通预览、CSV、JSON、INSERT SQL 导出。JSON SQL 值使用 UTF-8 十六进制输入再转换，避免依赖反斜杠模式。
- 改进插件中心无表上下文引导。

## 安全与兼容性

- 插件不提供数据库写入能力。真实样本读取仅通过 DBX Host 授权 API；原始样本不得进入日志、导出、持久化或生成结果。
- Preview、CSV、JSON、INSERT SQL 与 SQL 预览消费同一有效数据集；配置变化后旧结果不可导出。
- 插件 ID、最低 DBX 版本（`>=0.6.23`）、Host API 要求（`^1.4`）和 frontend-only universal 包契约不变；生产包不依赖系统 Node.js。
