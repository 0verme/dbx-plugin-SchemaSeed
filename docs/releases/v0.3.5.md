# SchemaSeed v0.3.5

## 功能与交互优化

- 精简预览操作区，以状态驱动的主按钮统一生成、换批、处理中、配置已变更及失败重试操作；配置变化后旧预览不可导出，避免将过期结果误认为当前配置的结果。
- 为字符串枚举候选值提供 Tag Input，支持逐项增删、键盘操作、批量粘贴和歧义确认；高级 JSON 编辑保留候选值的 JSON 类型，不强制转成字符串。无效草稿会阻止预览与导出。
- 将字段生成策略、生成约束和诊断迁入支持多标签切换的「高级设置」弹窗。弹窗编辑先保存在当前表的页面内草稿中，显式保存时校验并提交；取消/关闭可确认未保存修改。保存配置不会自动生成数据，旧预览会标记为过期并禁用导出。

## 兼容性与安全边界

- 除 Manifest 版本号外，插件 ID、最低 DBX 版本（`>=0.6.23`）、Host API（`^1.4`）、UI 入口及权限保持不变；仍为 frontend-only universal 插件包。
- 不新增数据库写入权限或数据库写入行为。真实数据采样仍仅在用户显式生成预览且 DBX Host 授权时，通过现有 Host API 执行；预览与导出继续使用同一有效数据集。
- 生产插件包无 Node.js Sidecar、backend 或 Node.js 运行时依赖；Node.js 仅用于开发、自动化检查和官方 DBX 打包工具。已检查 universal 包，不包含测试目录、fixtures 或真实采样数据。
