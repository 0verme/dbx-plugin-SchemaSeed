# SchemaSeed v0.3.3

### 新功能

- 可在工作台中预览当前生成数据集对应的 INSERT SQL，并复制完整语句；预览和 CSV、JSON、INSERT SQL 导出使用同一数据快照，不会执行数据库写入。
- 生成数量范围扩展为 1–1000 行（默认 50 行）；预览每页显示 50 行，导出仍包含完整生成结果。受 DBX 授权控制的采样探测最多读取 100 行、16 个候选字段。

### 体验优化

- INSERT SQL 预览改为居中弹窗，提供独立滚动、复制反馈、Escape 关闭和焦点管理；窄屏工作台采用更紧凑的布局，同时保留主要预览和导出入口。
- 从插件中心打开且没有当前表上下文时，显示清晰的选表指引，而不再展示空工作台和误导性错误；从表右键进入的操作保持不变。
- 精简工作台说明，将部分采样与授权说明收纳，降低主要操作区的信息负担。

### 问题修复

- 补齐 `CHAR(n)`、`NCHAR(n)` 和 `CHARACTER(n)` 字符类型识别，按声明长度限制生成值；未知类型和非法长度仍保留安全阻断，不强行补齐固定长度。
- 修复时间精度来源处理：优先采用 Host 结构化精度，其次识别受支持的显式时间类型精度；仅在必要时通过获授权的 MySQL 系统元数据查询补全。数据不可用时保留安全回退和精度未知提示，不把样本观测误当成数据库声明精度。

### 兼容性

- 最低 DBX 版本仍为 **0.6.23**，Host API 要求仍为 **1.4**；本次未提高最低版本要求。可选采样及 MySQL 元数据补全依赖 DBX Host Data API 和相应授权；不可用或拒绝授权时按安全策略回退。
- 发布包为 DBX 官方 universal 前端插件包，运行时不要求用户另行安装 Node.js；Node.js 仅用于开发、测试和构建。
- 用户已确认 Issue #82 的 Windows DBX 时间精度手动验收通过。该确认仅覆盖相应的 Windows 时间精度验收；macOS DBX Runtime 验收尚未完成，本版本不宣称所有平台均已完成真机验证。
